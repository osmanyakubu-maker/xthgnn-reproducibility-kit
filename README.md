# X-THGNN Reproducibility Kit

This repository provides the reproducibility archive accompanying the study:

**A Reproducibility-First Evaluation of Explainable Temporal-Heterogeneous Graph Neural Networks for Enterprise Attack Detection**

## Reproducibility Archive

The complete reproduction package is provided as:

`X_THGNN_Reproduction_v1.zip`

The archive contains the materials required to reproduce and audit the reported X-THGNN experiments, including experimental code, configurations, run outputs, evaluation resources, and supporting reproducibility documentation.

## Integrity Verification

`DEPOSIT_PACKAGE_SHA256.txt` provides the SHA-256 checksum for integrity verification of the deposited reproduction package.

After downloading the archive, users are encouraged to verify its SHA-256 digest before extraction or execution.

## Using the Archive

1. Download `X_THGNN_Reproduction_v1.zip`.
2. Verify the archive against `DEPOSIT_PACKAGE_SHA256.txt`.
3. Extract the ZIP file.
4. Read the documentation contained within the extracted archive before running the experiments.
5. Follow the supplied environment, data-preparation, training, evaluation, and reproduction instructions.

## Scope

This repository is intended to support transparent inspection and reproducibility of the experimental results reported in the associated study. Users should consult the documentation within the archive for dataset requirements, experimental settings, computational requirements, and known limitations.
